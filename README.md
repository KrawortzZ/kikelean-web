# Kikelean · Tótems NFC

Sitio web de Kikelean: tótems de acrílico con NFC y código QR para negocios de La Serena y Coquimbo.

- Páginas: inicio, nosotros, información legal y 404.
- Animaciones WebGL: tótem 3D con three.js (`src/hero-gl.js`) y ondas NFC con shader propio (`src/signal-gl.js`).
- Construido con [Vite](https://vite.dev). El header y el footer compartidos están en `partials/`.

## Uso

```bash
npm install
npm run dev      # desarrollo
npm run build    # genera dist/
npm run preview  # prueba la versión compilada
```
